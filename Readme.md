# 💾 Αυτοματοποιημένη Ρύθμιση USB Storage Pool με SnapRAID & Ειδοποιήσεις

Αυτό το script αυτοματοποιεί πλήρως τη δημιουργία ενός αποθηκευτικού χώρου (**storage pool**) από πολλαπλούς δίσκους USB, με χρήση του **SnapRAID** για προστασία δεδομένων (**parity**).

Περιλαμβάνει επίσης κοινόχρηστο φάκελο δικτύου μέσω **Samba**, καθώς και **ειδοποιήσεις μέσω email** για συγχρονισμούς και αποσυνδέσεις δίσκων.

---

## 🚀 Χαρακτηριστικά

* 🔐 **Προστασία δεδομένων:** Το SnapRAID παρέχει ασφάλεια από αποτυχία δίσκων (ανάλογα με τον αριθμό parity drives).
* 🌐 **Δικτυακή πρόσβαση:** Αυτόματο Samba share (`\\IP_ADDRESS\Storage`) προσβάσιμο από Windows, macOS & Linux.
* 📧 **Email alerts:** Ενημερώσεις για επιτυχημένους/αποτυχημένους συγχρονισμούς.
* ⚠️ **Έλεγχος αποσύνδεσης USB:** Άμεση ειδοποίηση αν κάποιος δίσκος χαθεί.
* 🤖 **Αυτοματοποίηση:** Χρήση `systemd timers` για sync, scrub & monitoring χωρίς χειροκίνητες ενέργειες.

---

## 📋 Προαπαιτούμενα

1.  Σύστημα με **Debian/Ubuntu/Raspberry Pi OS**.
2.  **2+ USB δίσκοι** (1 για parity, οι υπόλοιποι για data).
    * ⚠️ Ο **parity disk** πρέπει να είναι **ίσος ή μεγαλύτερος** από τον μεγαλύτερο data disk.
3.  **Gmail account** για ειδοποιήσεις.
4.  **App Password** από Google Account (δεν υποστηρίζεται ο κανονικός κωδικός).
    * Δημιουργία: [Google Security Settings](https://myaccount.google.com/security) → Ενεργοποίηση 2FA → Δημιουργία "**App password**".

---

## 🛠️ Οδηγίες Χρήσης

1.  **Κατέβασε & αποθήκευσε** το script (π.χ. `setup_storage.sh`).

2.  **Δώσε δικαιώματα εκτέλεσης:**
    ```bash
    chmod +x setup_storage.sh
    ```

3.  **Τρέξε το script με sudo:**
    ```bash
    sudo ./setup_storage.sh
    ```

4.  **Ακολούθησε τις οδηγίες στην οθόνη:**
    * Email & App Password Gmail
    * UUID δίσκου parity
    * UUIDs δίσκων data

    > 💡 **Σημείωση:** Το script εμφανίζει λίστα με όλους τους δίσκους & UUIDs για εύκολη επιλογή. Το UUID παραμένει σταθερό σε κάθε δίσκο, ακόμα κι αν αλλάξει η σειρά σύνδεσης (σε αντίθεση με `/dev/sdb`).

---

## ⚙️ Τι κάνει το Script

* **Εγκαθιστά πακέτα:** `snapraid`, `samba`, `mailutils`, `postfix`
* Δημιουργεί **config αρχείο** `/etc/snapraid.conf`
* Ρυθμίζει **Samba share** στο `\\IP_ADDRESS\Storage`
* Προσθέτει **cron/systemd timers** για:
    * `snapraid sync` (συγχρονισμός)
    * `snapraid scrub` (έλεγχος δεδομένων)
    * έλεγχο αποσύνδεσης δίσκων
* Στέλνει **email ειδοποιήσεις** για κάθε γεγονός

---

## 🔄 Ανάκτηση Δεδομένων

Σε περίπτωση αποτυχίας ενός δίσκου:

1.  **Αντικατέστησε** τον χαλασμένο δίσκο με έναν ίδιου ή μεγαλύτερου μεγέθους.
2.  **Κάνε mount** τον νέο δίσκο.
3.  **Τρέξε ανάκτηση:**
    ```bash
    sudo snapraid fix
    ```
    ➡️ Το SnapRAID θα ανακατασκευάσει τα δεδομένα στον νέο δίσκο χρησιμοποιώντας parity + υπόλοιπους healthy δίσκους.
